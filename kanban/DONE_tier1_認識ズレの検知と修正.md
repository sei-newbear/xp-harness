# 認識ズレの検知と修正

完了 (2026-08-06、v0.19.0 でリリース)。

噛み合っていない兆候 (質問がスルーされる / 訂正が続く / 話題を変えられる / 「そうじゃなくて」と返される) を観測したら出力を止め、短く認識を合わせ直す規律を追加した。

- `dialogue-principles`: 「対話の動作」に「ズレを検知したら止める」を新設 (シグナル / 検知したときの動作 / わからないときの動作 / やってはいけないこと)。再発火条件を description に追加
- `main.instructions.md`: 常時効かせる規律に「わからないまま進めない / 噛み合わなくなったら止める」を追加。skill 発火に依存させると、それっぽい回答で埋める 1 発目を止められないため
- `skill-design-style`: 原則 5 (依存の向きは instruction → skill の一方向) を追加。同じ規律が両層にあるのは重複ではない
- `skill-reviewer`: `name` の要否と description の字数の観点を `skill-design-style` に追随

検証は sandbox で 5 シナリオ、うち 3 シナリオで旧版との前後比較 (記録: `.claude/skills/harness-verification/references/2026-08-02_認識ズレ検知とworktreeセットアップ.md`)。効果が決定的だったのは 1 シナリオ (積み上げの無い明示的シグナルで、旧版は複数案 + 推奨の 4 択に逃げた) で、残りは回帰なしの確認。
