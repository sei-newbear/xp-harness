# 省略しないと一つずつ短くを同じ重さにする

完了 (2026-11-11)。「立場」「言葉」のカードとまとめて dialogue-principles をゼロから書き直した。「省略しない」は指示語・番号・記号を使わないことで量を増やすことではない、と切り分け、1 回の出力に問いは 1 つ・残りは「ほかに N 点」と一行で添える、理解の確認は別の出力にする、を同じ重さで置いた。harness-verification で新旧を 2 周 (48 本 + 60 本) 比べ、序盤の問いを 1 つにする振る舞いは新版で安定して上がった。記録は `.claude/skills/harness-verification/references/2026-11-11_dialogue-principles書き直し.md`。
